# CELPIP LS Crash Prep

https://veryvisa.github.io/celpip-ls/

An unofficial, noindex crash-prep study site for the CELPIP-General LS test (Listening and Speaking only), used for Canadian citizenship.
Chinese explanations first, English for all test language; three modes (中文 / EN+中 / EN). Practice prompts are original. Recordings stay in the browser.

This repository holds generated pages only.
