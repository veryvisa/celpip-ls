这套模考怎么进行How this mock works

  1. 找一个安静的地方，戴上耳机。点「开始模考」后浏览器只问一次麦克风权限。Find a quiet place and use headphones. After you press Start, the browser asks for the microphone once.
  2. 8 个任务按真实顺序和官方时间连着来：准备时间一到自动进入说话、自动录音；说话时间一到自动进入下一题。中间只有几秒的过渡，跟考场一样不能暂停。The 8 tasks run in the real order with official timings: when prep ends, speaking and recording start by themselves; when speaking time ends, the next task starts. There are only a few seconds between tasks and, as in the test centre, no pause.
  3. 每个任务随机抽一道题，优先抽你在这个浏览器里还没模考过的题，所以第二次模考是新题。Each task gets a random prompt, preferring ones you have not had in an earlier mock in this browser, so your second mock uses new prompts.
  4. 考完一起复盘：逐题听回放、看这道题自己的参考答案，按官方四个维度给自己打分。系统帮你找出最弱的 3 个任务，直接链到对应练习页。Afterwards, review everything at once: play each answer, read that prompt's own reference answer, and rate yourself on the four official dimensions. The page then names your 3 weakest tasks and links to their practice pages.
自评不是官方分数。它的用处是比较：同样的四个维度，第二次模考比第一次进步了没有、哪个任务一直最弱。真实级别请以官方模拟题和正式考试为准。Self-ratings are not an official score. Their use is comparison: on the same four dimensions, did your second mock improve on the first, and which task stays weakest? For a real level, use the official practice tests and the test itself.

    模考时最常见的三个问题The three most common problems in a mock

    • 时间没说满：说话时间还剩 20 秒就没话了。办法：每个要点都加一个「比如……」的具体例子。Not filling the time: you run out of words with 20 s left. Fix: add a concrete "for example …" to every point.
    • 开头卡壳：前 5 秒在「嗯……」。办法：每个任务背熟模板的第一句，开口先说它。A slow start: the first 5 seconds are "um …". Fix: memorise the first line of each task's template and say it first.
    • 前面一题没答好，后面心乱。办法：模考里也练「这题过去了」——下一题重新开始，每题单独评分。One bad task spoils the next. Fix: practise letting it go in the mock; every task is rated on its own.
